Definiowanie funkcji w Kotlinie

Funkcja to nazwany blok kodu, który wykonuje określone zadanie. W Kotlinie definiujemy je słowem kluczowym fun.

01 Podstawowa składnia

Każda funkcja składa się z kilku elementów. Przyjrzyj się anatomii poniżej:

fun nazwaFunkcji(parametr: Typ): TypZwracany {
    return wartość
}
fun słowo kluczowe — oznacza, że to funkcja
nazwaFunkcji identyfikator — dowolna nazwa (camelCase)
parametr: Typ wejście funkcji — może być ich wiele lub zero
: TypZwracany typ wartości którą funkcja oddaje do kodu

02 Parametry funkcji

Parametry to „wejścia" funkcji. Kotlin wymaga jawnego podania typu każdego parametru. Możesz też zdefiniować wartości domyślne.

bez parametrów
fun przywitaj() {
    println("Cześć!")
}
z parametrami
fun przywitaj(imię: String) {
    println("Cześć, $imię!")
}
wartość domyślna
fun przywitaj(imię: String = "świecie") {
    println("Cześć, $imię!")
}

03 Wartości zwracane i Unit

Int
fun suma(a: Int, b: Int): Int {
    return a + b
}

Zwraca liczbę całkowitą

String
fun powitanie(n: String): String {
    return "Cześć, $n!"
}

Zwraca tekst

Unit
fun loguj(msg: String): Unit {
    println(msg)
}

Nic nie zwraca — odpowiednik void. Można pominąć.

wyrażenie
fun kwadrat(x: Int) = x * x

Skrócona forma — typ wnioskowany automatycznie

04 Interaktywny przykład — uruchom funkcję

Wpisz dane i kliknij „Uruchom" — zobaczysz jak funkcja przetwarza parametry i zwraca wynik.

fun opisOsoby(
    imię: String,
    wiek: Int,
    język: String = "Kotlin"
): String {
    return "$imię ma $wiek lat i uczy się $języka."
}
// wynik: — kliknij Uruchom —
